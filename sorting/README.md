# 排序算法实现

用 JavaScript 实现的三种经典排序算法，每个文件都是独立的可运行程序。

## 运行方式

需要 Node.js 环境，在 `sorting` 目录下执行：

```bash
node bubble-sort.js   # 冒泡排序
node quick-sort.js    # 快速排序
node merge-sort.js    # 归并排序
```

## 算法对比

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|------|--------------|--------------|-----------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |

## 简要说明

- **冒泡排序**：相邻元素两两比较交换，简单直观，适合教学，数据量大时较慢。
- **快速排序**：分治 + 基准划分，实际应用中综合性能最好，但最坏情况会退化到 O(n²)。
- **归并排序**：分治 + 合并，时间复杂度稳定为 O(n log n)，但需要 O(n) 额外空间。
